# todoist-to-todotxt

A small CLI to export your Todoist tasks into [`todo.txt`](http://todotxt.org).

This project is for people who want a quick path out of Todoist and into the open [`todo.txt`](http://todotxt.org) ecosystem. It aims to make your tasks portable, local, scriptable, and easy to use with the many tools that already support the `todo.txt` format.

The goal is simple:

- read data from [`Todoist`](https://todoist.com)
- generate a local [`todo.txt`](http://todotxt.org) file
- keep the tool small, transparent, and automation-friendly

It is designed for users who want a practical migration bridge, a local backup, or a lightweight way to keep working with plain text task tooling.
